HUSH

The creature hears your heartbeat, breath and voice.

  • Camera reads pulse and breathing. Nothing is recorded.
  • Mic (optional) measures loudness only.
  • Press Esc anytime to stop the camera and mic.
Enter your Presage API key No key
Privacy details

Camera: opens only after you press "Play with camera". In that mode the Presage SmartSpectra SDK processes camera video to estimate pulse, breathing, blinking, talking and expression. HUSH uses these only as game signals.

Stored data: the app itself stores and uploads nothing. Processing is handled by the Presage SDK under Presage's privacy policy: https://api.physiology.presagetech.com/privacypolicy. SDK telemetry is disabled.

Microphone: optional and off by default. Only a loudness number is computed in memory; audio is never recorded, stored or uploaded.

API key: a key you enter is kept in memory for the session. It is saved only if you tick "Remember", encrypted with your OS keystore, and can be cleared at any time. It is only sent to Presage by the SDK.

Stopping: Esc (or the end screen) stops the camera and mic.

Not medical: HUSH is an entertainment game. It is not a medical device and makes no health claims.

Sit still and breathe normally.
